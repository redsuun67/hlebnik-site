# Интернет-магазин пекарни «Хлебник»

## Описание
Сайт на WordPress + WooCommerce, разработанный в рамках производственной практики ПМ.04.

## Место практики
ИП Памин Рудольф / Пекарня «Хлебник»

## Что внутри
- Тема: Astra
- Плагины: WooCommerce, Contact Form 7, Classic Editor, GA Google Analytics, Elementor, Akismet
- База данных: `shop.sql`

## Как развернуть
1. Установить OpenServer 5.4.3 (Apache 2.4, PHP 7.4, MySQL 8.0).
2. Скопировать папку `wp-content` в `C:\OpenServer\domains\shop.local`.
3. Импортировать базу `shop.sql` через HeidiSQL.
4. Создать домен `shop.local` в OpenServer.
5. Открыть `http://shop.local`.
